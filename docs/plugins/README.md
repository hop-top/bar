# Plugin docs

The compiled plugins that ship beside `bar`, one page each. The plugin protocol and the shell plugins in [`plugins/`](../../plugins/) are documented in [Plugins](../plugins.md).

- [bar-cliproxyapi](cliproxyapi.md): per-account quota of a CLIProxyAPI proxy as `#{cliproxyapi}`, and account switching with `bar cpa`.
- [bar-routellm](routellm.md): routing state of a RouteLLM router behind that proxy as `#{routellm}`, and the on/off switch `bar rtellm on|off`.
