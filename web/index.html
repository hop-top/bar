bar configurator

Build your Claude Code status line. Changes preview live.

The renderer is not built. Run make web in the bar repository, then reload this page.

Use it

  1. Install bar: download it from Releases or build it (install guide).
  2. Save the file as ~/.config/bar/bar.conf (or $XDG_CONFIG_HOME/bar/bar.conf): mkdir -p ~/.config/bar && mv ~/Downloads/bar.conf ~/.config/bar/bar.conf After Copy instead, paste into that file.
  3. Make it Claude Code's status line (shows the change to ~/.claude/settings.json and asks first): bar install --refresh 5 or add it by hand to ~/.claude/settings.json: "statusLine": { "type": "command", "command": "bar render", "refreshInterval": 5 }
  4. Check it: bar check Every setting is in the config reference.
